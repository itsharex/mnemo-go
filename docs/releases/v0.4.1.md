# Mnemo v0.4.1

`v0.4.1` 是一次稳定性与界面细节修复更新，重点处理启动主题、设置页空间利用、窗口控制键和账号侧栏的交互一致性。

## 改进

- 新安装时默认跟随系统明暗主题；已手动选择浅色或深色的用户设置不会被覆盖。
- 设置页右侧内容改为随窗口可用空间自适应展开，保留紧凑的阅读边距。
- 主窗口、通用二级弹窗、图片/音频预览和视频播放器的窗口控制键统一贴合右上角，取消按钮间分隔线与间隙。
- 账号侧栏保留收起态的清晰单层选中标记，并优化展开态账号切换的强调色过渡与点击命中。

## 验证

发布前执行 Go 格式检查、单元测试、静态检查、后端编译、前端单元测试与生产构建；正式安装包由发布工作流在干净环境中生成。
