# Mnemo v0.4.2

本版继续完善多网盘文件操作、预览与跨平台窗口交互。

## 改进

- 扩展部分网盘的回收站能力，并修正天翼云盘、移动云家庭云的目录及文件访问流程。
- 新增 PDF、Word、Excel、PowerPoint 只读预览；优化图片预览缓存和媒体预览关闭响应。
- 改进传输断点续传、账号切换、登录界面与侧边栏动效。
- 提高深色模式文字和选中态对比度；Linux/macOS 使用系统标题栏，避免与应用自绘窗口控制重复。

## 已知限制

- 天翼云盘回收站目前仍缺少列表和恢复接口；各网盘回收站及家庭云真实账号场景需在发布前继续验收。
- Linux/macOS 的窗口外观和安装包仍需在对应系统上验证；本地 Windows 构建不能替代跨平台验收。
