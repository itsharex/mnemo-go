# Mnemo v0.3.0

`v0.3.0` 是一次面向日常多云文件管理的功能与可靠性更新，重点改善工作区操作、媒体预览、同步/迁移正确性、传输控制、网盘兼容性和应用内更新体验。

Mnemo 不会尝试绕过网盘服务的验证码、短信验证、人机校验或风控策略；当服务端要求额外验证或拒绝请求时，应用会保留可恢复、可诊断的提示。

## 工作区与文件操作

- 新增双栏工作区搜索，可在源端与目标端之间更清晰地定位文件、准备复制或迁移。
- 同步任务支持在执行前查看计划；迁移任务会展示更完整的状态和细节，便于确认目标位置及失败原因。
- 完善拖放上传、文件列表交互、目录缓存和传输任务轮询，减少切换目录或账号时的陈旧界面状态。
- 增加阿里云盘 Open、123 云盘以及 OneDrive 工作/学校账号的原生云端收藏支持；没有可确认原生收藏接口的网盘仍安全使用本地收藏。OneDrive 个人账号保持本地收藏，避免调用不适用的接口。

## 预览与播放

- 支持独立预览窗口，媒体播放可在主工作区之外持续进行。
- 后台音频、播放结束后的续播状态清理、账号切换隔离和清晰度快速切换均得到修复，避免旧会话覆盖当前播放选择。
- 视频播放器支持 TS 时间戳定位与随机跳转续播；PikPak 转码播放以及媒体代理链路得到修复。
- 下载任务进度会同步至 Windows 任务栏，文本预览会在切换文件或关闭预览时取消过期读取请求。

## 同步、迁移与传输可靠性

- 同步执行会在关键阶段复核远端文件身份、大小、时间和内容指纹，上传准备后与下载落盘前也会再次检查，以降低同步期间远端变化造成的覆盖风险。
- 修复跨盘流式迁移阻塞、非完整下载响应被接受、同名目标处理以及取消信号未正确透传等问题。
- 下载 URL 的首次解析与过期重取均支持任务取消，暂停任务可更及时释放工作线程。
- 所有 HTTP 上传路径（包括分片、直传与 S3 multipart）统一受全局上传限速约束，同时保留重试、重定向和进度语义。
- 阿里云盘 Open 的断点上传会正确关联上传会话与文件 ID；同名同大小但内容不同的文件不再错误复用旧分片会话。
- 123 云盘秒传仅在服务端返回有效目标文件标识时判定成功；上传取消会如实向任务层报告。

## 网盘兼容性与账号体验

- 修复 Dropbox 根目录标识，文件列表读取与前端目录表示保持一致。
- 改善移动云盘短信登录重试和授权会话续接；容量展示适配移动云盘和天翼云盘的返回格式，并补充蓝奏空间展示。
- WebDAV 与 S3 的连接校验更轻量，代理与超时策略统一；避免将通用 WebDAV/S3 的 ETag 误当作内容 MD5 指纹。
- 多处上传、分享、目录列表、缓存隔离、错误传播与账号刷新边界得到收紧，降低无效请求、重复操作和跨账号状态串扰。

## 设置、更新与 Windows 安装

- 设置、日志路径和下载目录读取失败时不再悄然写回默认值；界面可获得明确错误并安全重试。
- 应用内更新流程强化了版本检查、下载、校验、替换与错误恢复；Windows 安装器支持更新后的静默重启，并分别适配 x64 与 arm64 架构。
- Release 工作流现在会在所有分支 push 与 Pull Request 上运行质量门；完整原生打包仍仅在标签或手动触发时执行，兼顾日常反馈与资源消耗。

## 安装包与校验

本次正式发布由 GitHub Actions 在干净环境中构建，并提供：

- Windows x64 / arm64 安装包；
- Linux x64 / arm64 的 `.deb`、`.rpm`、Arch Linux 包、AppImage 与 `.tar.gz`；
- macOS Apple Silicon 的 `.dmg` 与 `.tar.gz`；
- `SHA256SUMS.txt` 校验文件。

请优先从本 Release 下载对应平台的安装包，并在需要时使用 `SHA256SUMS.txt` 核验文件完整性。

## 已知限制

- 网盘的验证码、短信验证、人机校验、频率限制与账号访问策略完全由服务端决定；网络、地区、账号状态或请求频率都可能影响登录和传输。
- 同步在不提供条件写入的网盘上无法实现跨端绝对原子性；本版通过多阶段复核降低竞态风险，但不能替代服务端的原子版本控制。
- 是否能够跨账号或跨网盘秒传取决于目标服务是否允许复用内容指纹；若不可用，Mnemo 会按目标能力选择普通上传或报告明确错误。
