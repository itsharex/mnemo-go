# Mnemo v0.4.0

`v0.4.0` 是一次以界面换新、登录体验和多网盘可靠性为核心的正式更新。新版统一了图标与动效语言，重新组织网盘登录界面，并补齐错误通知、登录失效处理和跨启动目录缓存，让日常切换账号、打开根目录和处理失败任务更加直接、稳定。

Mnemo 不会绕过网盘服务的验证码、短信验证、人机校验、频率限制或访问策略。需要浏览器授权的网盘会直接进入真实授权流程，不再展示可能造成误解的中间页面。

## 界面与交互换新

- 通用界面图标迁移到统一的 Lucide 映射层；网盘品牌 Logo 继续保留各自品牌识别，并统一限制 SVG 与位图 Logo 的显示尺寸。
- 引入经过锁定的 Motion for Vue 动效能力，用于登录、快捷命令、全局搜索、传输中心和预览状态的轻量结构过渡；大列表和高频播放状态仍使用低开销 CSS 反馈。
- 精简首页、设置、空状态与侧栏中的冗余说明，降低视觉噪声；OLED 开关位置、传输中心导航、双栏焦点和拖放反馈得到整理。
- 图片、视频、音频、代码和 Markdown 预览的舞台与状态提示进一步统一，支持 `prefers-reduced-motion` 降级，减少不必要的位移与闪动。
- 顶栏与主要操作继续以紧凑图标呈现，保留键盘、焦点、ARIA 和深色/OLED 主题兼容。

## 登录页与账号体验

- 重做“添加网盘”界面：左侧使用紧凑服务列表，右侧使用统一标题、Logo 容器和表单布局；每个网盘都有独立、等尺寸的视觉入口。
- OAuth 网盘直接使用浏览器授权；账号密码、Cookie、短信验证码以及 WebDAV/S3 连接按各自真实登录方式呈现。
- 登录、验证码和连接错误统一转换为简短、可执行的中文提示，后端请求 ID、调用栈和服务端原始详情不再直接暴露在界面中。
- 后端仅在网盘明确确认令牌或凭据失效时自动移除本地账号；网络中断、限流、服务端 5xx、普通 403 或单个文件权限不足不会误删账号。
- 登录失效后会显示专门提示，说明本地账号已移除但云端文件不会删除，并可直接回到对应网盘重新登录。

## 多网盘错误通知

- 目录、搜索、上传、下载、分享、同步、迁移、预览和账号刷新统一接入全局通知；错误按登录失效、网络、权限、配额、限流、验证码、冲突、目标不存在和服务异常分类。
- 传输中心会为下载、上传和迁移失败提供面向用户的原因，并对同一失败事件去重，避免轮询期间重复弹出通知。
- 13 个现有网盘驱动补充明确的凭据失效分类；S3 的 `ExpiredToken`、`InvalidAccessKeyId` 等结构化错误也会进入同一登录失效流程。

## 根目录长期预缓存

- 所有已登录网盘会在后台静默预热根目录第一页，最多同时处理两个账号，避免账号切换时集中占用网络。
- 根目录快照保存在安装目录的 `data/cache`，跨会话、跨重启长期有效；命中已有缓存时启动过程不会再次访问网盘。
- 支持分页的网盘只预取第一页；不支持分页的网盘安全回退到普通目录接口。前台完成的完整目录快照不会被较晚返回的第一页覆盖。
- 打开网盘时先显示长期缓存，再在后台刷新真实目录；远端最新结果到达后会自动替换缓存。
- 长期快照不会保存易过期的下载链接和缩略图签名；手动移除账号、确认登录失效或清除缓存时会同步清理对应数据。清除缓存后会立即重新静默预热已登录网盘。

## 工程与兼容性

- 前端依赖锁定 `@lucide/vue@1.34.0`、`motion-v@2.4.4` 与兼容 CI Node 20 的 `@vueuse/core@14.1.0`，继续使用 Vue 3.5、Vite 6 和 Wails v2。
- 新增图标映射、错误提示、根目录预热、长期缓存、账号缓存清理和登录失效回归测试。
- 本版保留 13 个现有网盘：PikPak、OneDrive、Dropbox、123 云盘、蓝奏云、优享版蓝奏云、139 云盘、天翼云盘、一刻相册、阿里云盘 Open、光鸭云盘、WebDAV 和 S3。

## 安装包与校验

本次正式发布由 GitHub Actions 在干净环境中构建，并提供：

- Windows x64 / arm64 安装包；
- Linux x64 / arm64 的 `.deb`、`.rpm`、Arch Linux 包、AppImage 与 `.tar.gz`；
- macOS Apple Silicon 的 `.dmg` 与 `.tar.gz`；
- `SHA256SUMS.txt` 校验文件。

请从本 Release 下载对应平台的安装包；如需核验文件完整性，可使用同页提供的 `SHA256SUMS.txt`。

## 已知限制

- 网盘缓存用于快速呈现，不替代服务端实时状态；进入目录后仍会在后台刷新，因此短时间内可能先看到上次缓存，随后更新为最新内容。
- 首次登录、手动清除缓存后的首次预热，以及从未缓存过的目录仍需要等待网盘响应。
- 网盘验证码、短信、人机验证、频率限制和地区/账号访问策略由各服务端决定，Mnemo 只提供明确提示和可恢复入口。
- 本轮自动验证覆盖构建、单元测试、竞态检查和后端静态检查；按当前开发约定未执行浏览器截图或浏览器工作区视觉验收。
