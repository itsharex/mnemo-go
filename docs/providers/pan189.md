登录恢复边界：`loginSubmit` 返回非零 result 时，即使带有 toUrl 也按失败处理。账密登录收到“刷新页面后重试”（兼容空白字符）或 Session 接口的 `LoginRespIsNull` 时，最多重建一次登录参数；其他 HTTP 400 不盲目重试。短信验证通过后暂存跳转凭据，Session 换取暂时失败时允许手动重试该步骤，不重复提交一次性短信码；明确失效后清除会话并要求重新获取验证码。模拟回归已覆盖，真实账号登录仍待验证。

账号刷新先使用现有 Session 请求容量（家庭云验证目录访问），不再每次强制续期。文件接口以 HTTP 400/401 返回 `InvalidSessionKey` 时也会进入一次自动恢复；换取 Session 的 GET 遇到网络错误或 HTTP 408/502/503/504 最多延迟重试一次，限流和其他明确拒绝不盲目重试。open token 轮换成功但后续 Session 换取失败时，保留新 open token 和原 API Session。续期接口在真实账号下返回 `userSession` XML，现同时解析 JSON 与 XML。2026-09-24 使用本机已登录账号只读验证，家庭云目录列表成功。

## 10. RefreshAccount（refresh.go）

✅ 个人云：使用现有 Session 调用 `/portal/getUserSizeInfo.action`，读取 `cloudCapacityInfo`，仅在失效时自动续期；兼容数字/字符串容量字段，失败保留上次成功值并报告错误。

✅ 家庭云：同一容量接口读取独立的 `familyCapacityInfo`，必要时使用家庭会话与 `familyId` 再查一次；不与个人云容量相加，缺失时不显示家庭云容量。模拟接口回归通过，真实账号容量待实际使用确认。

旧版账号曾保存个人云与家庭云的合并容量；升级后刷新成功前暂不展示这份旧容量，避免侧边账号栏短暂显示错误数值。
