## 2. 文件列表（s3.go）

连接校验：配置 `BasePath` 时直接执行带该前缀、`Delimiter=/`、`MaxKeys=1` 的 `ListObjectsV2`，跳过不适合前缀权限账号的 `HeadBucket`；桶根挂载先 `HeadBucket`，仅在 403/405/501 时回退最小列表请求。校验整体限制 60 秒（含 SDK 重试）；新增账号不会默认试写对象。HTTP 客户端优先使用应用代理，否则使用 Windows 手动系统代理。

✅ `s3.go:95-136` ListObjectsV2 + Delimiter:/ 模拟虚拟目录。CommonPrefixes→目录，Contents→文件。

> ✅ 已增加 seen token 防重复游标保护；服务端返回截断但缺少下一页游标时会明确失败。

## 3. 下载（s3.go）

✅ `GetDownloadURL` 使用 `PresignGetObject` 生成预签名 URL（默认 4h redirect），并以 Unix 毫秒回填 `ExpireTime`；`GetVideoPreview` 提供原画源并交给统一的网页播放会话链路。

## 7. 临时分享（share.go）

✅ 通过 S3 `GetObject` 预签名 URL 创建单文件临时访问链接，只提供 1 天、7 天选项；不支持提取码，也不保存到本地分享历史。该链接不是服务商托管的永久分享，凭据有效期或权限不足时可能提前失效。

## 本轮审计结论

1. ✅ **forcePathStyle 可配置**，并支持 `sessionToken` 与 `BasePath`。
2. ✅ **目录递归操作已实现**：分页列举、批量删除、目录复制和自嵌套保护。
3. ✅ **上传冲突策略已实现**：包括目录冲突、连续重名探测和 `skip`。
4. ✅ **大文件上传与复制已实现**：multipart upload/copy 均在失败时清理未完成会话。
5. ✅ **S3 404 兼容处理已实现**：同时识别 `NotFound`、`NoSuchKey` 和 HTTP 404，保留权限/服务端错误。
6. ✅ **分页游标重复/缺失保护已实现**。
7. ✅ **CopySource 按路径段编码**，特殊对象名可复制。

仍属设计范围的能力：S3 不提供统一回收站、服务商托管分享和云端搜索接口。当前仅暴露安全边界明确的临时预签名访问链接。
