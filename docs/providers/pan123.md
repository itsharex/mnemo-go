## 1. 登录（pan123.go）

收藏已接入官方网页使用的原生接口：`GET /restful/goapi/v1/file/starred/list` 与 `POST /restful/goapi/v1/file/starred`（均复用现有 `/b/api` 基址、鉴权、限速和重登流程）。列表按 `page/pageSize/next` 完整读取，写入参数为 `fileIdList` 和 `starredStatus`（收藏 `255`、取消 `1`）。兼容收藏列表的 `fileSize/fileType`，保留大整数文件 ID 和父目录。模拟 HTTP 回归覆盖分页、字段映射、取消、异常列表和业务失败；未进行真实账号写入验证。核查来源：[官方网页](https://yun.123pan.cn/)，2026-09-10。
